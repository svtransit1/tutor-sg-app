## Violation Summary

### 🔴 Blocker (0)
None. All screens have basic `testID` coverage for E2E testing.

### 🟡 Major (3)
| # | Violation | Affected Screens | Fix |
|---|-----------|-----------------|-----|
| M2-A11Y-01 | Interactive elements missing `accessibilityRole` | All screens | Add `accessibilityRole="button"` to all `TouchableOpacity` elements used as buttons |
| M2-A11Y-02 | Progress bar lacks `accessibilityRole="progressbar"` and value | ModelDownloadScreen | Add `accessibilityRole="progressbar"` and `accessibilityValue={{ min: 0, max: 100, now: progress }}` |
| M2-A11Y-03 | Text-only interactive states without icons | All screens | Add icons alongside all button labels (check ADD §9 "no-text-only states") |

### 🔵 Minor (4)
| # | Violation | Affected Screens | Fix |
|---|-----------|-----------------|-----|
| M2-A11Y-04 | Progress text 14px below 16pt minimum | ModelDownloadScreen | Increase `progressText` fontSize to 16 |
| M2-A11Y-05 | Kid detail text 14px below 16pt minimum | KidProfileScreen | Increase `kidDetail` fontSize to 16 |
| M2-A11Y-06 | ActivityIndicator has no accessibility label | DeviceTierScreen, ModelDownloadScreen | Add `accessibilityLabel` to loading spinners |
| M2-A11Y-07 | Step/detail lists use plain Text without list semantics | ConsentScreen, FirstHomeworkScreen | Use `accessibilityRole="list"` + `accessibilityRole="listitem"` or announce via `accessibilityLabel` |

## Recommendations

### Before M2 DoD
1. Add `accessibilityRole="button"` to every `TouchableOpacity` that acts as a button — this is a one-line fix per element.
2. Fix the two font sizes below 16pt: progress text (ModelDownloadScreen) and kid detail (KidProfileScreen).
3. Audit contrast ratios programmatically — recommend using `@react-native-community/accessibility-engine` or a contrast checker tool.

### Post-M2
1. Add icons to all buttons per ADD §9 visual spec (waiting for brand guide/icon set).
2. Consider adding `react-native-accessibility-engine` for automated CI accessibility checks.
3. Add accessibility labels for ActivityIndicator components.

## Contrast Quick Check
| Foreground | Background | Ratio | Pass? |
|------------|-----------|-------|-------|
| #4A90D9 (button bg) | #FFFFFF | ~2.8:1 | ❌ Fails WCAG AA (needs ≥3:1 for large text, ≥4.5:1 for body) |
| #FFFFFF (button text) | #4A90D9 | ~2.8:1 | ❌ Fails for small text; passes for large text (>18pt bold) |
| #1A1A2E (kid name) | #FFFFFF | ~15:1 | ✅ |
| #666666 (subtitle) | #FFFFFF | ~5.4:1 | ✅ Body text |
| #173B2B (promise title) | #F2FBF5 | ~14:1 | ✅ |

The button color #4A90D9 as a background for white text passes WCAG AA for large text (≥18pt) but may fail for smaller elements. Consider darkening to #3A7BC8 or increasing contrast.
