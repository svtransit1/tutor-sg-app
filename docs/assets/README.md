# docs/assets/

Screen-flow specs, UI handoff notes, and visual references. Pinned visual sources of truth that outlive individual issue threads.

## What goes here

- Screen-flow diagrams and specs
- UI handoff notes (annotations, design rationale)
- Visual style guide references
- Brand guide snapshots (once pinned by Foxy)

## What does NOT go here

- Live Figma links → project references (link from wiki)
- Research → `docs/research/`
- Individual screenshot attachments → issue thread
